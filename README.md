One line, 200 characters, on the dumbest thing my agent did today: it spent 45 minutes debugging a script before realising it had been editing the copy in `/tmp` the whole time. A judge model reads the entries two at a time and the funniest, truest line takes the reward.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (override the directory with `OUTPUT_DIR`).
